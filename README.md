# 𝙥𝙧𝙤𝙟𝙚𝙘𝙩 // 𝙧𝙚𝙮𝙮𝙩𝙤𝙤𝙡𝙨.𝙫𝟮

Video toolkit berbasis browser untuk patch, encode, dan upscale video.

## Fitur

| Fitur | Deskripsi | Tier |
|-------|-----------|------|
| **MAGIC PATCH** | Patch metadata MP4 instan (tanpa re-encode) | Basic (2x/hari) |
| **ADVANCED ENCODE** | Re-encode H.264 via FFmpeg.wasm | Premium |
| **AI UPSCALE (Local)** | Upscale foto via ONNX Waifu2x | Premium |
| **AI UPSCALE (Cloud)** | Upscale video via Colab/Ngrok API | Premium |
| **ANALYZER** | Cek kualitas upload TikTok | Basic (5x/hari) |
